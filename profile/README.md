## Maris3D: build 3D scenes in Blender by describing them

A small model that runs offline and turns plain words into scene-building steps in Blender, with Maris, an on-screen assistant who builds with you.

- [Product page](https://slm4apps.github.io/maris3d/)
- [Code and add-on](https://github.com/slm4apps/maris3d)
- [Model on Hugging Face](https://huggingface.co/slm4apps/Maris3D-SLM-Blender-0.5B-GGUF)

## Why small models

- They run on an ordinary laptop, with no network and no account.
- Each one is trained for one app, so it stays small, fast and predictable.
- Code, docs and model weights are open: Apache-2.0.

## Follow along

New models and releases are announced on the [website](https://slm4apps.github.io/) and on [Hugging Face](https://huggingface.co/slm4apps). Questions and bug reports: open an issue in the repository of the product you use.
